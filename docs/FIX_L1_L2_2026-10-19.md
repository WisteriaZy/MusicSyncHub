## ✅ L1: mappings API 独占位守护

### 问题描述
**位置**: `app/mappings_api.py`  
**端点**: `PUT /api/mappings`, `POST /api/mappings/one`  
**风险**: 虽然映射规则改动极快（<50ms），但理论上扫描任务可以在修改期间开始，基于过期的映射规则操作

### 修复方案
1. 新增 `mappings` kind 到 `EXCLUSIVE_KINDS`
2. 两个写端点添加 `exclusive_slot("mappings")` 守护

### 修改文件

#### `app/core/jobs.py`
```python
# 修改前
EXCLUSIVE_KINDS = {"sync", "move", "organize", "collect", "upload", "trash",
                   "tags", "station", "cleanup", "transfer",
                   "scan", "upload-commit"}

# 修改后
EXCLUSIVE_KINDS = {"sync", "move", "organize", "collect", "upload", "trash",
                   "tags", "station", "cleanup", "transfer",
                   "scan", "upload-commit",
                   # ★ mappings 写映射规则文件，虽然操作极快（<50ms），
                   #   但为了保持一致性（所有写操作都占独占位），也纳入独占。
                   "mappings"}
```

#### `app/mappings_api.py`
```python
# 修改前
from fastapi import APIRouter, Body, HTTPException

@router.put("/api/mappings")
def put_mappings(payload: Dict[str, Any] = Body(...)) -> Dict[str, Any]:

@router.post("/api/mappings/one")
def put_one(payload: Dict[str, Any] = Body(...)) -> Dict[str, Any]:

# 修改后
from fastapi import APIRouter, Body, Depends, HTTPException
from .core.guard import exclusive_slot

@router.put("/api/mappings")
def put_mappings(payload: Dict[str, Any] = Body(...),
                 _job=Depends(exclusive_slot("mappings"))) -> Dict[str, Any]:

@router.post("/api/mappings/one")
def put_one(payload: Dict[str, Any] = Body(...),
            _job=Depends(exclusive_slot("mappings"))) -> Dict[str, Any]:
```

### 验证方法

### 影响评估

## ✅ L2: 测试文件资源泄漏修复

### 问题描述
**位置**: 
- `tests/test_player_queue.py:53`
- `tests/test_player_queue.py:164`

**现象**: 测试结束时 `gc.collect()` 报 `ResourceWarning: unclosed file`

**风险**: 仅测试期间，生产环境无影响（测试完自动清理）

### 修复方案
用 `with` 上下文管理器显式关闭文件

### 修改文件

#### `tests/test_player_queue.py`
```python
# 修改前（第一处）
class QueueShapeContractTest(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.src = open(APP_JS, encoding="utf-8").read()

# 修改后
class QueueShapeContractTest(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        with open(APP_JS, encoding="utf-8") as f:
            cls.src = f.read()

# 修改前（第二处）
class QueueBehaviourTest(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        import shutil
        cls.node = shutil.which("node")
        cls.src = open(APP_JS, encoding="utf-8").read()

# 修改后
class QueueBehaviourTest(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        import shutil
        cls.node = shutil.which("node")
        with open(APP_JS, encoding="utf-8") as f:
            cls.src = f.read()
```

### 验证方法


### 影响评估
- **兼容性**: 完全兼容，行为无变化
- **性能**: 无影响（文件立即关闭更好）
- **测试稳定性**: 提升（消除警告）
