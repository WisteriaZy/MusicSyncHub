## Critical 级修复 (已完成 3/3)

### ✅ C1: 跨进程锁释放逻辑错误

**问题**: 空字符串 token 能通过 `if tok not in holder` 检查（Python `"" in "any_string"` 为 True），导致误释放其他进程的锁。

**后果**: 双写同一批文件。

**修复** (`app/core/proclock.py:114-119`):
```python
# 修复前
if not tok:
    return
holder = _read_holder(p)
if tok not in holder:  # ❌ 空串总是 in
    return

# 修复后
if not tok or not tok.strip():
    return
holder = _read_holder(p)
if f"|{tok}|" not in f"|{holder}|":  # ✓ 精确匹配
    return
```

**测试**: 892 项测试全部通过

### ✅ C2: 封面缓存上限 cap=0 被解读为无限制

**问题**: `cap=0` 时跳过淘汰循环，缓存无限增长；配置读取失败时虽设默认值但已写入缓存。

**后果**: 内存泄漏。

**修复** (`app/deps.py:185-201`):
```python
# 修复前
try:
    cap = int(load_config().settings.cover_cache_size) or 800
except Exception:
    cap = 800
with _cover_lock:
    _cover_cache[ck] = (payload, mime)  # ❌ 已写入
    _cover_cache.move_to_end(ck)
    if cap > 0:  # ❌ cap=0 不淘汰
        while len(_cover_cache) > cap:
            _cover_cache.popitem(last=False)

# 修复后
try:
    cap = int(load_config().settings.cover_cache_size) or 800
except Exception:
    cap = 800
if cap <= 0:  # ✓ cap=0 直接禁用缓存
    return Response(content=payload, media_type=mime, ...)
with _cover_lock:
    _cover_cache[ck] = (payload, mime)
    _cover_cache.move_to_end(ck)
    while len(_cover_cache) > cap:  # ✓ 无条件淘汰
        _cover_cache.popitem(last=False)
```

### ✅ C3: junction 穿越路径检查

**问题**: 相对路径只检查 `has_dotdot()`，未调用 `inside_root_real()` 检测 junction 穿越。

**绕过路径**: 在源根内创建 junction 指向外部，相对路径访问可读取外部文件。

**修复** (`app/deps.py:655-684`):
```python
# 修复前
if P.has_dotdot(p):
    raise HTTPException(400, f"{what}不允许包含 ..")
return p.strip("/")  # ❌ 相对路径未检查 junction

# 修复后
if P.has_dotdot(p):
    raise HTTPException(400, f"{what}不允许包含 ..")
abs_path = src.abs_path(p)
if not P.inside_root_real(root_n, abs_path):  # ✓ 检查真实路径
    raise HTTPException(400, f"{what}经过目录联接指向了数据源之外")
return p.strip("/")
```

### ✅ H2: 校验失败隔离文件时间戳冲突

**问题**: 多文件同一秒失败时 `.bad-<timestamp>` 名字冲突，后一个覆盖前一个。

**修复** (`app/core/transfer.py:180-186`):
```python
# 修复前
def _quarantine(src, path: str) -> str:
    import time as _t
    tgt = f"{path}.bad-{int(_t.time())}"  # ❌ 时间戳冲突
    try:
        src.move(path, tgt)
        return tgt

# 修复后
import threading
import uuid
_quarantine_lock = threading.Lock()

def _quarantine(src, path: str) -> str:
    tgt = f"{path}.bad-{uuid.uuid4().hex[:8]}"  # ✓ UUID 避免冲突
    with _quarantine_lock:
        try:
            src.move(path, tgt)
            return tgt
        except Exception:
            try:
                src.remove(path, hard=True)
                return ""
            except Exception:
                return ""
```
