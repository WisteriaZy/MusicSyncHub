#### 2.2 `exclusive_slot` 的正确性
**原理**: 真正占位的守护（之前的 `exclusive_guard` 只是检查，不占位）

```python
# app/core/guard.py:50-113
def exclusive_slot(kind: str):
    """返回一个 yield 依赖，请求期间持有，响应后释放
    
    解决的真实漏洞（外部审计定为 Critical）:
    - 用户批量改 500 首标签（可能几十秒）
    - 期间 busy() 仍是 None
    - 另一个页面可以合法开始扫描、移动
    - 两个写流程同时基于过期状态操作
    """
    def _dep(...):
        job = get_jobs().create(kind, owner=x_msh_client)
        try:
            yield job
        except BaseException as exc:
            get_jobs().finish(job, error=str(exc))
            raise
        else:
            get_jobs().finish(job)
    return _dep
```

**采用端点**: `tags_write`, `tags_restore`, `station_*`, `trash_*`, `folders_*`  
**修复前后对比**: 修复前 7 个写端点可并发执行，修复后全部互斥

# ✅ 正确的锁粒度
